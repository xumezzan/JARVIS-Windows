# Главный экран по референсу

15 октября 2026. Изменение главного экрана в `desktop/` по прямому запросу
пользователя. Новые интеграции и этапы 10–32 не реализовывались.

## Результат и границы

[Исходное изображение](../reference/ui.png), 1672×941, сохранено из приложения пользователя.
Основная композиция адаптирована к заданному окну **1536×1024**: сайдбар 180 px,
верхняя строка 52 px, колонки 361 / 436 / 479 px с промежутками 20 px.
`src/tokens.css` создан, поскольку готового файла токенов в репозитории не было.

Стек: Electron, React, Vite, TypeScript, Tailwind, lucide-react, framer-motion.
Карточки используют 20 px, padding 24 px, границу 1 px rgba(255,255,255,.07),
полупрозрачную заливку и мягкую тень. Акцент #3F7BFF; цвета логотипов/статусов
воспроизводят референс. Jarvis — 56 px / 200; LISTENING... — 13 px / .4em.
Inter Variable поставляется локально. Сфера — отдельный математический canvas-компонент
с синими нитями; положение и свечение меняются плавно, reduced motion останавливает движение.

Это отдельная оболочка дизайна: Python-приложение, PermissionEngine, подтверждения,
аудио и аккаунты не заменены. События, приложения, действия, имя профиля и время на главной
— иллюстративные данные из референса. Ввод запускает только демонстрацию; настоящих
команд, записи микрофона, подключений и отправки сообщений здесь нет.
Фото профиля заменено иконкой пользователя; логотипы приложений — небольшие авторские
векторы. Процедурная сфера воспроизводит образ, но её нити отличаются от растрового
свечения исходника. Разница сторон изображения и окна также исключает буквальное
совпадение всех пикселей; заданные пользователем размеры, отступы и шрифты имеют приоритет.

## Финальные проверки

[1536×1024](../desktop/qa/desktop.png) ·
[1280×900](../desktop/qa/compact.png) ·
[390×844, полная страница](../desktop/qa/mobile.png) ·
[Electron](../desktop/qa/electron.png).

`npm run build` прошёл. `npm run qa:verify` проверяет точные шрифты/токены,
открытие деталей, пустой ввод, запуск/отмену/завершение демо, удержание и отпускание
кнопки голоса, отмену при потере фокуса, историю, навигацию, темы и анимацию.
На трёх размерах проверены горизонтальное переполнение и размещение строк действий
внутри карточки. Результаты: [verification.json](../desktop/qa/verification.json).

Финальная независимая проверка выявила и исправила доступные имена компактной навигации,
переполнение длинных команд, плотность карточек на узких размерах и контраст подписи
дизайн-превью. Размер canvas ограничен CSS grid, чтобы его внутренний pixel buffer
не расширял страницу после изменения окна. Мобильная карточка действий имеет естественную
высоту, чтобы текст не попадал под следующую карточку.

`npm run qa:electron` запустил настоящее frameless окно на Mac с содержимым **1536×1024**,
проверил minimize, maximize/restore, close, sandbox, contextIsolation, отсутствие Node в
renderer и четыре метода preload. Использован документированный macOS параметр
[enableLargerThanScreen](https://github.com/electron/electron/blob/main/docs/api/structures/base-window-options.md),
поскольку текущая область экрана ниже 1024 px. [Результаты](../desktop/qa/electron-verification.json).
Независимый финальный обзор: **SHIP** в пределах standalone preview; [разбор](../desktop/qa/review.md).

IPC проверяет отправителя и URL главного frame; внешние переходы, popups, webviews и
запросы разрешений заблокированы. Vite доступен только на 127.0.0.1:5173.
