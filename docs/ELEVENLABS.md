# Дополнительный голос: ElevenLabs Free

Реализован по отдельному запросу пользователя. По умолчанию Jarvis использует локальный
системный TTS; подключение ElevenLabs необязательно. Это Free-тариф облачного сервиса
с ограниченным количеством кредитов, а не безлимитный локальный синтез.

## Подключение

1. Создайте личный Free-аккаунт на [ElevenLabs](https://elevenlabs.io/).
   Условия регистрации принимает пользователь. Не подключайте платный тариф или overages.
2. В кабинете создайте API-ключ с доступом к Text to Speech, чтению Voices и User/subscription.
3. В Jarvis откройте микрофон → **Настроить голос ElevenLabs Free…**.
4. Введите ключ в защищённое поле и нажмите **Сохранить ключ**. Не отправляйте его в чат.
   Ключ хранится в Windows Credential Manager / macOS Keychain, сервис `Jarvis/ElevenLabs`.
5. Нажмите **Загрузить голоса и проверить Free-лимит**, выберите стандартный голос.
6. Прочитайте пояснение, отметьте согласие и нажмите **Прослушать пробу**.
   Текст пробы показан в окне. Каждая проба расходует лимит.
7. Для следующего итога отметьте согласие заново и нажмите **Озвучить следующий итог**.
   После одного итога снова используется системный голос. Выбор с согласием не сохраняется
   между запусками; повторное открытие настроек, смена ключа/голоса, отключение озвучки,
   Stop и закрытие сбрасывают соответствующее согласие.

Нужны установленные голосовые зависимости (`.[voice]`); Windows-установщик их включает.
Если ключ ограничен слишком строго, Jarvis покажет ошибку доступа; права меняет пользователь.
При отказе/исчерпании квоты повторной отправки нет. Локальная озвучка остаётся доступна.

## Граница передачи и расходов

- Только HTTPS `api.elevenlabs.io`: GET подписки, GET стандартных голосов, POST синтеза.
  Нет смены тарифа, платёжных методов, прокси, cookies, редиректов, произвольных URL/preview URL.
- Перед каждым POST требуется свежий ответ `tier=free`, обе overage-возможности `false`,
  `max_credit_limit_extension=0`, корректные целочисленные счётчики и достаточный остаток
  с консервативной оценкой один кредит на символ. Неизвестные значения блокируют синтез.
- Проверка и POST не являются транзакцией на стороне провайдера. Не меняйте биллинг
  аккаунта параллельно озвучке. Jarvis не управляет оплатой и не даёт гарантии поведения
  стороннего сервиса при изменении его условий/API.
- Передаются только фиксированная проба или детерминированный краткий итог `spoken_result`.
  Исходная команда, распознанная речь, содержание писем и результаты инструментов
  в этот адаптер не попадают. OpenAI-планировщик имеет своё отдельное согласие.
- ElevenLabs может хранить переданный текст и созданное аудио. Zero Retention не заявляется:
  отключение серверного логирования доступно только Enterprise.
- Инструменты в Simulation не выполняются, но отдельно разрешённая озвучка использует
  сеть и кредиты. Это явно написано перед флажком согласия.
- Flash v2.5, русский язык, PCM 16 kHz / mono / int16. До 500 символов и 30 секунд
  возвращённого аудио; только RAM. Ключ, API и воспроизведение — в ограниченном helper,
  отмена/таймаут завершают и собирают процесс. Уже принятый сервером запрос может
  расходовать кредиты даже при отмене или ошибке воспроизведения; автоматического retry нет.
- При закрытии сохраняется только явно сохранённый ключ. Кнопка удаления стирает его
  из системного хранилища; история провайдера этим не удаляется.

## Официальные основания (проверены 15.09.2026)

- [Список голосов](https://elevenlabs.io/docs/api-reference/voices/search): фильтр premade.
- [Подписка и overages](https://elevenlabs.io/docs/api-reference/user/subscription/get).
- [Синтез и форматы](https://elevenlabs.io/docs/api-reference/text-to-speech/convert).
- [Voice Library](https://elevenlabs.io/docs/eleven-creative/voices/voice-library):
  её голоса недоступны Free-пользователям через API. В Jarvis пока только premade.
- [Тарифы](https://elevenlabs.io/pricing/api): размер лимита берётся из аккаунта,
  фиксированное число бесплатных минут в коде не обещается.

## Проверка

Обычные тесты используют синтетические ответы и хранилища, без настоящих ключей,
микрофона, динамиков и API. Настоящее звучание, Free-аккаунт и Windows ещё не проверены.

На Windows после установки:

```powershell
.\.venv\Scripts\python.exe -m pytest tests/unit/test_elevenlabs.py tests/integration/test_elevenlabs_ui.py tests/unit/test_voice.py tests/integration/test_voice_ui.py
.\.venv\Scripts\python.exe -m jarvis
```

В видимом приложении выполните подключение выше, прослушайте одну пробу и проверьте
русское произношение. Затем выберите одну озвучку итога и запустите офлайн-команду
`проверь систему дважды` в симуляции: речь должна описывать симуляцию, микрофон выключен.
Проверьте Stop/Escape во время пробы, возврат к локальному TTS, удаление ключа и повторное
открытие без согласия. Не меняйте аккаунт на платный ради теста: негативные сценарии
подписки проверяются fixtures. Запишите фактический результат, не публикуя ключ/ответ API.
