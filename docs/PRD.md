# Product Requirements — Jarvis 0.1

## Проблема и пользователь

Пользователь Windows 11 хочет выполнять короткие рабочие задачи обычной речью или
текстом, сохраняя контроль над отправкой информации и изменением данных. Первый
профиль — индивидуальный специалист, работающий в Chrome, Notepad и VS Code.
Русские команды входят в голосовую приёмку. Профессия, проекты и контакты помогают
разрешать ссылки, но неоднозначный адресат всегда требует уточнения.

## Главный цикл

Команда → контекст → ограниченный план → типизированный инструмент → разрешение →
выполнение → проверка результата → журнал → понятный ответ.

## Приёмочный сценарий MVP на Windows

1. Запустить приложение и ввести команду или нажать микрофон с видимым индикатором.
2. «Открой Chrome и найди OpenAI»: увидеть Chrome, поиск и проверенные результаты.
3. «Открой Блокнот и напиши Jarvis test successful»: увидеть точный текст, прочитанный
   обратно из элемента редактора через UI Automation.
4. Проверить follow-up команду с сохранённым контекстом выбранного приложения.
5. Подготовить тестовое внешнее действие: увидеть сервис, аккаунт, адресата, тему,
   содержание и вложения до подтверждения.
6. Убедиться, что до подтверждения исполнение технически невозможно. После подтверждения
   исполняется только показанный снимок действия; изменения требуют нового согласия.
7. Увидеть каждый выполненный, отклонённый, отменённый и ошибочный шаг в журнале.
8. Остановить выполняемую задачу: новые шаги не запускаются, незавершённый результат
   не объявляется успешным.

Тестовый adapter доказывает границу разрешений на этапе 2; он не считается настоящей
отправкой письма. Реальный Gmail/Outlook подключается на этапе 8 через OAuth/API.
MVP целиком считается готовым только после Windows E2E и упаковки на этапе 9.

## Функциональные требования

| Область | Требования |
| --- | --- |
| Desktop UI | idle, listening, thinking, awaiting approval, executing, success, error; текст, transcript, план, activity, подключения, настройки, stop |
| Windows | открыть/сфокусировать allowlisted приложение, перечислить окна, вводить текст в конкретный элемент и проверять его |
| Browser | Playwright, поиск и чтение, семантические элементы, политика доменов и проверка действий |
| Planner | только зарегистрированные tools, строгая валидация, лимит шагов/времени, уточнение неоднозначности |
| Voice | push-to-talk, видимая расшифровка до исполнения, STT/TTS adapter, отмена кнопкой и голосом |
| Memory | профессия, приложения, проекты, роли, предпочтения; просмотр/изменение/удаление; без секретов |
| Communication | подключить/отключить, прочитать, создать draft, показать полный preview, подтвердить точную отправку |

## Нефункциональные требования

- UI не блокируется ожиданием сети или adapter; работой управляет отменяемая задача.
- Действия ограничены timeout и числом шагов; неизвестные инструменты отклоняются.
- Simulation показывает SIMULATED, проходит ту же политику и не вызывает реальные adapters.
- Локальное хранение по умолчанию; сетевые интеграции явно подключаются пользователем.
- Credentials не попадают в модель, память или журнал. Чтение внешнего содержимого
  не повышает его доверие и не разрешает новые действия.
- Первый запуск воспроизводим; реальные Windows-проверки отделены от mock-тестов.

## За пределами первого MVP

Переводы, покупки, изменение паролей, произвольный shell/код модели, скрытое наблюдение,
поддержка всех программ, мобильные приложения, multi-tenancy и автономный фоновый режим.
Микросервисы не нужны. CRITICAL остаётся отключённым. Коммерческие профили и подписанные
обновления относятся к последующим релизам.

## Граница текущего этапа

Этапы 0–4 создали desktop shell, проверенный PermissionEngine и Windows-адаптер.
Текстовая команда остаётся демо. Ручное окно инструментов предоставляет open/focus/list
для Notepad, Chrome, VS Code и CONFIRM-ввод в пустой Notepad с read-back.
Native Windows-приёмка не выполнена; локальные probe-тесты не доказывают работу UIA.
Добавлен ручной Playwright browser: статическое анонимное чтение, поиск, ввод и GET-формы
с exact approvals. JavaScript, произвольный POST и существующие профили не поддерживаются.
Planner, голос и внешние сервисы ещё не реализованы.
