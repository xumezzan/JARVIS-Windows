# Открытые решения

Дата: 2026-09-15. Это список решений для будущих этапов, а не ответы от имени пользователя.
Ни один пункт не разрешает подключение аккаунта, покупку, запись экрана или внешнее действие.
Документирование продолжается без этих ответов; решение требуется перед зависимой реализацией
или приёмкой. Ближайшая незавершённая работа — **M9, native Windows и упаковка**.
Нумерация этапов: [ROADMAP.md](ROADMAP.md); ограничения сервисов: [INTEGRATIONS.md](INTEGRATIONS.md).

## Какие решения нужны раньше

- **Сейчас, для продолжения M9:** целевой Windows 11 x64 ноутбук/профиль; реальные
  пользовательские действия для голоса, тестовый Microsoft-аккаунт и получатель выбираются
  пользователем непосредственно в безопасном процессе приёмки. D02/D03 фиксируют границы;
  отсутствие ответов о будущих сервисах не мешает M9.
- **Перед первыми расширениями:** D01/D04/D08/D09 определяют порядок и подготовку
  EN/RU, общего контракта, wizard и Asana/Calendar.
- **Перед соответствующей интеграцией:** D05–D12/D17 закрываются только для выбранного
  сервиса, без блокировки независимых модулей.
- **Перед корпоративной памятью, фоном и demonstrations:** D13–D16/D18/D19 определяют
  доступ, хранение и автономность. D20/D21 остаются отдельными воротами поздних изменений.

Документы и официальные API могут измениться до реализации. Закрытие решения требует
датированного результата для выбранного account/tenant/version; ссылка на документацию,
макет кнопки или успешная fixture-проверка не заменяет такой результат.
