  До исправления четыре регрессионных случая выбирали `browser.search`.

  наблюдается идентичность окон, затем повторно проверяется и подробно читается
  выбранное окно. Таймауты, проверка цели и защита непустого редактора сохранены.
- Четыре падавших на этой Windows теста читают UTF-8 отчёты с явной кодировкой.

## Граница результата и следующая проверка

Универсального переноса содержимого из одного произвольного окна в другое пока
нет: отсутствуют чтение содержимого окна, общий клик, клавиши и буфер обмена.
Есть чтение текстовых файлов/API и запись в файлы/API или наблюдённое поле.
Бинарного копирования файлов и разбора локальных DOCX/PDF/XLSX тоже пока нет.

Офлайн-провайдер понимает фиксированные рецепты. Текущий облачный маршрут использует
DeepSeek и может перейти к OpenAI после двух шагов; многошаговая проверка требует
информированного согласия на обоих получателей. В этом прогоне облачные запросы
не выполнялись. Выбор офлайн/облако сбрасывается при перезапуске, хотя отдельно
сохранённые согласие и модель сохраняются.

Следующий приёмочный сценарий: небольшой тестовый текстовый файл → точная копия
в другом файле → пустое поле Блокнота с проверкой результата. Для реального
переноса между рабочими приложениями владелец выбирает приложения и пример данных.
Asana и прочие живые сервисы, голос, постоянный браузер, чистая ОС и полный MVP
остаются отдельными открытыми воротами.
