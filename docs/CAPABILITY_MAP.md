# Карта возможностей JARVIS

Дата сверки: **2026-09-15**. Документ сопоставляет продуктовую цель с прочитанным кодом
и отчётами; он не добавляет реализацию. Исходное рабочее дерево было чистым до начала
документационной задачи. В этой задаче не запускались application tests, lint, build,
GUI, Windows, microphone или live-service проверки; аккаунты не подключались.
Результаты старых прогонов остаются историческими свидетельствами соответствующих отчётов.

Источники: [PRD](PRD.md), [ROADMAP](ROADMAP.md), [ARCHITECTURE](ARCHITECTURE.md),
[SECURITY](SECURITY.md), отчёты и исходные файлы по ссылкам ниже. Отдельный оригинал плана
v1.0 не найден; сохранены доступные требования и порядок этапов 0–9. Последний номерной
отчёт — [M9](MILESTONE_9.md), но его native acceptance ещё не завершена. Дополнение
[ElevenLabs](ELEVENLABS.md) и [UI refinement](UI_REFINEMENT.md) сохраняют собственные
исторические результаты и не закрывают M9.

## Как читать таблицы

- **Локально реализовано** — код существует в указанной границе; это не утверждение
  о native Windows, живом API или реальном оборудовании.
- **Частично** — реализована только явно описанная часть возможности.
- **Предложено** — функции нет; API-документация, кнопка, макет, mock, установленное
  приложение или подписка не доказывают её готовность.
- Все этапы **10–32 предложены, не реализованы**, и следуют после обязательного M9.
  Столбец dependencies перечисляет дополнительные предпосылки по ROADMAP; подключать
  неиспользуемые сервисы ради другого адаптера не требуется. Условные writes M29–32
  не разрешают CRITICAL автоматически; BLOCKED остаётся запрещённым.
- Критерий готовности описывает **будущую проверку**, а не выполненный в этой задаче тест.
  Эффект проверяется отдельно от планирования, подключения и HTTP-ответа.

## Каждый запрошенный сервис

Официальные capabilities, auth/scopes, account types, источники с датой и ограничения
собраны в [INTEGRATIONS.md](INTEGRATIONS.md). Ни одна строка «предложено» не означает
подключённый аккаунт. Для каждого сервиса обязательны minimal read probe, account selection,
revocation/expiry, rate limits, incomplete coverage, cancellation и no uncertain-write retry.

## Граница готовности продукта

Ближайший exit — полный [M9 Windows acceptance](WINDOWS_ACCEPTANCE.md), включая packaging
и чистую установку. Завершённый MVP даёт ограниченного локального помощника с отдельным
Planner, Windows/browser tools, русским local voice, явными memory labels и Outlook;
он не означает завершённую полную продуктовую цель.

M10–12 дают English/Russian foundation, расширяемые connections и onboarding; M13–21 —
поэтапно принятые интеграции; M22–24 — новые строго ограниченные execution/context routes;
M25–28 — память компании, процессы/роли, background и demonstrations. M29–32 — условные,
отдельно согласуемые семейства внешних изменений. Полные future E2E сценарии находятся
в [PRODUCT_ACCEPTANCE.md](PRODUCT_ACCEPTANCE.md); необходимые решения —
[OPEN_DECISIONS.md](OPEN_DECISIONS.md). Нумерация и точный ближайший prompt определены
в [ROADMAP.md](ROADMAP.md).
