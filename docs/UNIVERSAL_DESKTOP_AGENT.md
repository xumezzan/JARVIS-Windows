# Универсальное управление компьютером — 05.11.2026

Решение владельца: пользовательский пример не становится отдельным рецептом,
инструментом приложения или регулярным выражением для распознавания команды.
`AGENTS.md` содержит новое главное архитектурное правило.

Electron и обычный launcher используют `OpenAIProvider`, модель по умолчанию `gpt-4o`.
Старые настройки `offline`/пустая модель мигрируют в OpenAI/`gpt-4o`. Отсутствие ключа
даёт диагностическую ошибку credentials; обхода на скрытый offline-рецепт нет.
OfflineProvider оставлен только для явно заданных диагностических действий/тестов.
Ключ вводит владелец в системное хранилище, он не хранится в репозитории.

## Поток задачи

1. После текущего cloud disclosure Runner получает через PermissionEngine список
   окон, активное окно и текстовый буфер. В simulation адаптеры не вызываются.
2. Модель получает свободный запрос, каталог доступных инструментов и наблюдения.
3. Модель выбирает один следующий атомарный шаг: окно, инспекция/скриншот, клик,
   текст/клавиша, буфер, браузер, файл или restricted Python computation.
4. PermissionEngine валидирует, классифицирует и аудирует шаг; native helper
   повторно проверяет процесс и выбранное окно. Изменяемый заголовок не идентичность.
5. Модель наблюдает результат и продолжает до выполнения запроса или явной ошибки.
   Марки локальны последней актуальной инспекции; старые марки после ввода истекают.

Никаких tools для Calculator/Notepad, таблиц AppId или Chrome-команд по шаблонам нет.
Названия реальных коннекторов, роли Accessibility/UIA, форматы протоколов и коды клавиш
остаются платформенными контрактами, а не рецептами пользовательских задач.

## Универсальные примитивы

- `windows.open_app`: произвольное название/ярлык/путь приложения (`app`, также `query`
  как совместимый вход). Windows использует Start Menu, AppsFolder, App Paths, PATH,
  AppData/Program Files; macOS — каталоги `.app` и локализованные метаданные.
  Запуск без shell и без пользовательских аргументов.
- `windows.focus_app`: точный target, handle или подстрока title/process. Неоднозначный
  выбор требует уточнения, а не случайного переключения.
- `windows.type_text`: необязательные target/editor. При их отсутствии используется
  активное окно. UIA/AX предпочтительны; иначе clipboard paste с восстановлением.
- `windows.click_element`: element, mark_id или x/y; AX/UIA action либо физический
  клик по актуальному элементу/точке в пределах текущего окна.
- `windows.send_hotkey`: одна комбинация модификаторов и клавиши, без shell/скриптов.
- Остальные инструменты: инспекция/скриншот, буфер, браузер, файлы, sandbox вычислений.

Обычные desktop-действия SAFE. Идентифицированные внешние/необратимые действия,
включая Outlook send, оплату, публикацию и удаление, остаются CONFIRM.
Чужой текст не меняет политику и не выдаёт approval. У неизвестной координаты нет
надежной семантической классификации: универсальный GUI не доказывает обратимость
любой кнопки. Перед внешними обязательствами планировщик должен запросить exact approval.
URL handoff запрещает localhost и literal private/link-local/loopback IP; это локальная
валидация адреса, не полноценная SSRF/DNS-rebinding защита удаленного транспорта.
Strict Browser и сетевые коннекторы сохраняют собственные сетевые политики.

## Проверка и ограничения

Проверки охватывают неизвестные имена/пути приложений, активное окно без TextPattern,
изменяемые заголовки, марки, координаты, clipboard restoration, отсутствие скрытых
рецептов и передачу пользовательской задачи LLM. Итоговые результаты прогонов и
обновления установленного приложения записываются ниже после выполнения.

Универсальный набор примитивов не гарантирует успех в каждой программе. Разрешения
ОС, secure/password controls, скрытые окна, недоступные изображения/деревья и поведение
конкретного редактора могут ограничить действие. Квитанция физической вставки
`performed=true, text_verified=false` не доказывает принятие текста приложением.
Live OpenAI, голос/микрофон и native Windows acceptance проверяются отдельно.

Локально выполнены Ruff, format check, mypy (371 файлов), pip check, сборка Python
пакета, изолированный GUI smoke (`success (simulated)`), frontend build и 34 Electron
contract tests. Отдельные прогоны: 182 macOS adapter tests и 153 Windows fixture tests.

Реальный Mac fixture и установленная сборка: [native result](qa/universal-macos-20261105.json),
[installation receipt](qa/universal-installed-20261105.json). Проверены все 22 файла
manifest, codesign и реальное состояние READY, OpenAI · gpt-4o. Сохранён режим
симуляции владельца; настоящая облачная задача этим запуском не подтверждена.
Точный итог полного pytest и CI хранится в PR ветки `fix/universal-desktop-agent`.

SAFE desktop effects тоже записываются в durable journal. Для намеренного повтора
одинакового ввода (например, два Tab) выбирается новая occurrence только после
SUCCESS предыдущей. Незавершённая или неопределённая попытка сохраняет ключ и
блокирует автоматический повтор, в том числе после перезапуска.
