# Design System: Jarvis Desktop

Визуальная основа — [пользовательский референс](../reference/ui.png). Продуктовые факты и реализованные границы — [PRODUCT.md](PRODUCT.md). Активный код находится в `desktop/`; прежнее `design-preview/` заменено.

## Идентичность

Тёмный glassmorphism, один синий акцент #3F7BFF, локальный Inter Variable. Заголовок Jarvis: 56px, вес 200. Статус под заголовком: 13px, uppercase, letter-spacing .4em. READY / WORKING / LISTENING отражают состояние движка. Сфера — отдельный процедурный canvas-компонент с синими нитями, не картинка референса.

Все цвета, радиусы, отступы и переходы задаются в `src/tokens.css`. Основа #080f16 / #060c12, текст #f1f4fc, вторичный #9aacc5. Карточки: rgba(20,29,39,.52), 1px rgba(255,255,255,.07), 20px, padding24px, мягкая тень, blur20px. Зелёный предназначен только для подтверждённых статусов, розовый — для ошибок.

## Композиция

Frameless Electron content1536×1024, sidebar180px, titlebar52px. Главная сетка — три колонки 0.83fr / 1fr / 1.1fr, gap20px. Слева — реальная статистика сеанса, история и подключение Outlook. В центре — заголовок, сфера, состояние, текущая команда, голосовые кнопки и composer. Справа — реальные шаги, результат и переход к настройкам.

До1340px sidebar становится76px, отступы уплотняются. До950px колонки складываются, ассистент первым. Длинная команда переносится и прокручивается с доступным началом текста; карточки не перекрывают содержание. На коротком окне разрешена вертикальная прокрутка страницы.

Навигация: Ассистент, Действия, Инструменты, Подключения, Память, Настройки. На пустом старте карточки показывают отсутствие задач/истории, счётчики равны нулю. Нет фиктивных встреч, имени пользователя, успешных шагов и подключений.

## Поведение

Composer отправляет реальную задачу Python-движку. Режим симуляции выбирается явно; успех и ошибки поступают из Runner. Stop отменяет выполняющуюся задачу. Никаких таймеров фиктивного завершения.

Кнопка микрофона удерживается прямо в Electron: отпускание останавливает запись, потеря фокуса, Stop и Escape отменяют её. Настройки, память, Outlook, точные подтверждения и облачное согласие встроены в React; Python работает без Qt. Запись и approval проходят через доверенные жесты isolated preload и проверки main, а точный prompt snapshot имеет TTL и одноразовый Python capability. Автозапуск выключен по умолчанию; порог confidence >= 0.75 не даёт облачного согласия или approval. Успешный `finished` может озвучить русский `spoken_summary` до 300 символов; предупреждения и детерминированный fallback сохраняются для остальных статусов и отсутствия действий. Системный TTS локален, ElevenLabs требует одноразового согласия на уже показанный точный итог; подробности — [VOICE_RUNTIME.md](../docs/VOICE_RUNTIME.md). Навигация/фокус/hover/disabled имеют видимые состояния, transitions180ms; Framer Motion и canvas учитывают reduced motion. Canvas ограничивает частоту30fps и останавливается в скрытом документе.

Темы Midnight/Graphite и переключатель анимации меняют только оформление текущего сеанса. Статус подключения всегда берётся из runtime; недоступный движок не заменяется демонстрацией.

## HUD

Обновление 2026-10-25: само главное окно во время working/running становится
интерактивным alwaysOnTop HUD 360×120 в правом верхнем углу workArea с отступом 16px.
Внутри — сфера 48px, режим/номер шага, текущий инструмент, Stop и «Открыть».
Обе кнопки имеют высоту 44px. Stop сохраняет синий акцент и тёмный текст с
контрастом 5.13:1; Inter и остальные tokens сохранены по пользовательскому референсу.
При завершении/ошибке/отмене возвращаются bounds, minimum/maximum size, resizable,
alwaysOnTop и maximized. Approval/clarify показывают полное окно с фокусом; если
исходный монитор отключён, окно возвращается на доступный дисплей. «Открыть» сохраняет
обычный режим до следующей задачи. Актуальный снимок — qa/task-hud.png.

Прежнее display-only окно 320×110 снизу справа остаётся только для фоновых подсказок
и явного индикатора включённого wake-микрофона, без управления или approval API.
Отдельная синяя полупрозрачная рамка перед кликом живёт 300 мс,
не принимает фокус/мышь и не содержит управляющих кнопок.

## Фоновые подсказки

Сеансовые переключатели — в существующих настройках. Компактные предложения в
основном окне показывают действие и «Скрыть»; тема и точный адрес видны только
здесь. Тот же corner HUD показывает generic offer без получения фокуса или
скрытия workbench. Сфера мягко мигает дважды; reduced motion выключает мигание.
Подсказки имеют TTL, ограниченную очередь и не создают task/approval сами.
